# Ideen – Elospeed StemPacker

🇬🇧 *This file is kept in German. English readers: see the [README](../README.md).*

Lose Ideen, nicht eingeplant. Was eingeplant ist, steht in der [ROADMAP](../ROADMAP.md).

- **4-Deck-Vorhörer:** vier fertige Stem-Dateien gleichzeitig abspielen (16 Spuren, gemeinsamer Start), so wie der erste Tester sie in Traktor auf vier Decks nutzt. Grundlage: 16-Spur-Engine aus StemDecks (`deckengine.pas` im StemMaker-Repository). Erst nach dem Traktor-Test fragen, ob er das braucht.
- **Vorhören vor dem Packen:** Master und die vier Quelldateien eines Songs direkt im StemPacker abspielen (stumm/solo), um die Zuordnung zu prüfen.
- **Ein Unterordner pro Song** erkennen (wie Demucs: `Song\drums.wav`, `Song\bass.wav` …): der Songname käme dann aus dem Ordnernamen.
- **Eigene Vorlagen speichern** (Muster, Namen, Farben) statt nur „Eigene“.
- Bewusst **nicht** geplant: DVDs einlesen, `.cue`-Dateien schneiden. Dafür gibt es eigene Werkzeuge.
