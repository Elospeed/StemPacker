Example for StemPacker (simple test tones, 5 seconds each, no real music)

  Downmix\   Song One (DOWNMIX #1).wav ...   = master files
  Channels\  Song One (A).wav ... (D).wav    = stems 1-4 (A, D stereo; B, C mono)

In StemPacker: drag this Example folder onto the window (or click
"Choose folder ..." and pick it). StemPacker detects the 5.1 DVD naming
by itself and lists the three songs. Then click "Pack all". The stem
files appear next to the master files in Downmix\.

By hand: tick "Set folders and patterns myself", preset "5.1 DVD",
Master folder = Example\Downmix, Stem 1 folder = Example\Channels
(leave Stem 2-4 empty), "Find songs", then "Pack all".
